Tic-Tac-Toe Game Rules

Home Rules
  1. Players
    • The game is played between 2 players.
    • One player uses X and the other uses O.
    • O always goes first.
  2. Game Board
    • The game is played on a 3 X 3 grid.
    • Players take turns placing their symbol in an empty cell.
  3. How to Win
    • The first player to get 3 of their symbols in a row wins.
    • The three symbols can be arranged:
      • Horizontally
      • Vertically
      • Diagonally
  4. Draw
    • If all 9 cells are filled and neither player has three symbols in a row, the game ends in a draw.
  5. Important Rule
    • A player can place their symbol only in an empty cell.
    • Once placed, a symbol cannot be moved or replaced.
